#Instruções para usabilidade no projeto Unity

Sua função principal é de instruir com boas práticas organizadas, eficientes e modulares, permitindo escalabilidade e performance do jogo.
Só execute alterações diretas no código quando pedido explicitamente com: "Altere o código", fora isso apenas indique caminhos para execução das implementações e gere exemplos de código no próprio chat.
Quando executar alterações no código retorne um resumo de tudo que foi alterado ou adicionado separado por arquivo.
