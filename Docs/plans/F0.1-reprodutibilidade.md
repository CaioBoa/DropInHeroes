## 3. Decisões técnicas

### D1 · LFS: migrar histórico ou adotar daqui em diante? ⚠️ destrutivo

| | **A · LFS daqui em diante** | **B · Migrar histórico** |
|---|---|---|
| Como | `.gitattributes` + `git lfs track`; commits novos usam LFS | `git lfs migrate import --everything` + `push --force` |
| `.git` | Continua 1,2 GB para sempre | Encolhe drasticamente |
| Clone novo | Baixa 1,2 GB de histórico | Baixa só o necessário |
| Risco | Nenhum | **Reescreve todos os SHAs**; exige force-push |
| Reversível | — | Só com backup do `.git` |

**DECIDIDO EM 2026-08-03: A — LFS daqui em diante.**

Consequências aceitas:
- O `.git` permanece em ~1,2 GB. Um clone novo baixa esse histórico.
- **O passo 5 (migração de histórico + force-push) sai do plano.** Nenhuma operação reescreve SHAs; nada precisa de force-push.
- O benefício do LFS vale só para binários commitados a partir de agora — que é a maior parte do volume futuro, dado o alvo de 40-60 personagens.

Se um dia o tamanho do clone incomodar, a opção B continua disponível — e fica mais cara a cada mês.

## 9. Achado crítico do Passo 2 — registro permanente

**A migração havia quebrado o chão da cena principal, silenciosamente.**

`Assets/Scenes/TowerRun.unity`, GameObject `Grid/Ground`: o Tilemap tinha **61 de 106 entradas de tile mortas** e **24 de 69 sprites mortos**, porque a limpeza de `Assets/Art/Palettes/` apagou os 61 Tile assets de `CityProps/` com que o chão foi pintado, e a limpeza de `ModernExteriors` apagou a textura-fonte `3_City_Props_48x48.png`. Sem erro de compilação e sem erro de console — o chão simplesmente deixaria de renderizar.

### Por que quase passou despercebido

A varredura só encontrou o problema porque foi feita com `SerializedProperty.Next(true)`. Com `NextVisible(true)` — o idioma mais comum — a mesma cena reportava **1** referência quebrada em vez de **86**: o array de tiles do Tilemap (`m_TileAssetArray`) é uma propriedade **oculta**, e `NextVisible` não a enxerga.

> **Norma derivada:** auditoria de referência quebrada em Unity usa `Next(true)`, nunca `NextVisible(true)`.

### Reparo aplicado

`git restore --source=HEAD --worktree` sobre 124 arquivos (61 `.asset` + 1 `.png` + seus `.meta`), identificados cruzando os GUIDs citados pela cena com os `.meta` presentes em `HEAD`.

| Métrica | Antes | Depois |
|---|---|---|
| GUIDs mortos citados pela `TowerRun` | 62 | **0** |
| `Grid/Ground` — tiles válidos | 45/106 | **106/106** |
| `Grid/Ground` — sprites válidos | 45/69 | **69/69** |
| GUIDs não resolvidos no projeto inteiro | 71 | **9** (todos pré-existentes) |

A cena foi recarregada (`isDirty=False`, sem perda) para eliminar o estado quebrado em memória — enquanto ele existisse, um `Ctrl+S` teria gravado o Tilemap sem as referências e tornado a perda permanente.

### Efeito colateral tratado

Restaurar arquivos dentro de pastas cujos `.meta` estavam apagados fez o Unity **recriar 5 `.meta` de pasta com GUID novo**. Verificado que nenhum deles era referenciado (nem hoje, nem em `HEAD`), e os originais foram restaurados para manter a árvore consistente.
